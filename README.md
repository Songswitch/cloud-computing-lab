# 素数判断小程序

一个用 Python 编写的简单命令行程序，输入一个正整数，判断它是否为素数。

## 功能

- 交互式输入，即时输出判断结果
- 试除法优化：排除偶数、只检查到 √n，减少不必要的循环

## 运行环境

- Python 3.x
- 无第三方依赖，直接使用标准库

## 使用方法

在终端中运行：

```bash
python prime_checker.py
```

按提示输入整数即可，示例：

```
请输入一个正整数: 97
97 是素数

请输入一个正整数: 100
100 不是素数
```

## 算法说明

素数（质数）指大于 1，且除了 1 和自身外没有其他因数的自然数。

本程序的判断逻辑：

1. 小于 2 的数不是素数；2 是最小的素数。
2. 除 2 以外的偶数都不是素数，直接排除。
3. 对其余的数，只需用奇数试除到 √n 为止——如果 n 存在大于 √n 的因数，那么必然存在一个对应的小于 √n 的因数，因此无需检查到 n。
