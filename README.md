## 程序使用说明

运行环境：Python 3.x，无第三方依赖。

```bash
python prime_checker.py
```

按提示输入正整数即可判断是否为素数，输入 `q` 退出程序。示例：

```
请输入一个正整数（输入 q 退出）: 97
97 是素数
请输入一个正整数（输入 q 退出）: 100
100 不是素数
请输入一个正整数（输入 q 退出）: q
程序已退出
```

## 算法说明

采用试除法：小于 2 的数不是素数；2 是最小的素数；除 2 以外的偶数直接排除；其余数只需用奇数试除到 √n 即可。
